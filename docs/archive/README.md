# Archived planning documents (June 2025)

The files in this directory are historical planning and strategy documents written between 13 and 27 June 2025 (dates from `git log`), when this repository was a Web3 identity / context / micropayment project and then a content-marketplace pivot. They were moved here from the repository root on 2026-10-21.

They describe **intentions at the time, not the current state of the code**. In particular:

- Numbers in them (coverage percentages, revenue projections, user counts, market sizes, timelines, funding rounds) were never verified and should not be quoted.
- Phases, milestones and "complete" checkmarks refer to plans, not to shipped or tested software.
- Nothing they describe was deployed to any network or reviewed by an independent security party.
- The "MCP server" they plan is not the Model Context Protocol; the one real MCP server in this repository is [`vault/`](../../vault/README.md), written in October 2026.

For what actually exists and is tested, read the [root README](../../README.md).
